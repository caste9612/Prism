Prism 2.1.3 keeps large network folders and NTFS disks up to date with far less work, and lets the content analysis of busy file servers move forward. It includes the fixes of 2.1.2, which was tried on one PC and not published.

## Fixes

- **Network folders read again in full** — on a busy file server, a change made directly in a
  top-level folder (even just its date, when a file is created in it) made Prism read the whole
  shared folder again: 3.2 million entries, 6 to 9 minutes, back to back all working day. Prism
  now reads only the list of each folder that changed; subfolders it already knows stay as they
  are, and new ones are read in full. A complete re-read happens only when Windows loses
  notifications, spaced as in 2.1.1.
- **NTFS disks not updated** (2.1.2) — Prism reads the files changed on an NTFS disk through
  Windows, which gives their records already corrected. A record can still hold, as ordinary
  data, the value Windows uses to check it: Prism took those records for damaged ones and tried
  the same update again every 16 seconds, so the catalog of the disk stayed where it was. Those
  records are now read normally. And when the updates of an NTFS disk fail one after the other
  for 10 minutes, whatever the reason, Prism reads the disk again from its file table (seconds)
  and starts again from there.
- **Content analysis that did not move forward**
  - The analysis always leaves one worker free, so the updates of the disks start at once
    instead of stopping an analysis: on a PC with many disks, the analysis of a large network
    folder restarted every few minutes.
  - Updating a few folders of a network share no longer stops the analysis of the other shares
    of the same server.
  - Images too large to be compared (over 512 MB, such as virtual slides) no longer count as
    work left: the analysis of a folder full of them restarted every 2 minutes doing nothing.
  - Files modified in the last 10 minutes wait for a later round: a file rewritten all the time
    is no longer read again at every round.
  - When the only files left are in use, unreadable or changed since the catalog was updated,
    the next round comes after 30 minutes instead of 2 (2.1.2).

## Install

Prism 2.0 and 2.1 update themselves: *Settings › Updates › Install and restart*. Otherwise
download `Prism_2.1.3_x64-setup.exe` below and run it (Windows 11, 64-bit). The installer is
not signed yet: if SmartScreen says "Windows protected your PC", choose *More info › Run anyway*.

## In italiano

Prism 2.1.3 tiene aggiornate le grandi cartelle di rete e i dischi NTFS con molto meno lavoro, e
fa avanzare l'analisi del contenuto dei file server affollati. Comprende le correzioni della
2.1.2, provata su un PC e non pubblicata.

- **Cartelle di rete rilette per intero**: su un file server affollato, un cambio fatto
  direttamente in una cartella di primo livello (anche solo la sua data, quando ci si crea un
  file) faceva rileggere a Prism tutta la condivisione: 3,2 milioni di voci, da 6 a 9 minuti,
  una dopo l'altra per tutta la giornata di lavoro. Ora Prism rilegge solo l'elenco di ogni
  cartella cambiata; le sottocartelle che conosce già restano come sono, quelle nuove si leggono
  per intero.
- **Dischi NTFS non aggiornati** (2.1.2): un file letto tramite Windows poteva essere preso per
  rovinato, e il journal di tutto il disco restava fermo dietro di lui. Ora quei file si leggono
  normalmente; e se gli aggiornamenti di un disco NTFS falliscono di fila per 10 minuti, per
  qualsiasi motivo, Prism rilegge il disco (pochi secondi) e riparte da lì.
- **Analisi del contenuto che non avanzava**: l'analisi lascia sempre libero un posto, così gli
  aggiornamenti dei dischi partono subito senza fermarla; aggiornare poche cartelle di una
  condivisione non ferma più l'analisi delle altre condivisioni dello stesso server; le immagini
  troppo grandi per il confronto (oltre 512 MB, come i vetrini virtuali) non contano più come
  lavoro da fare; i file modificati negli ultimi 10 minuti aspettano un giro successivo; quando
  restano solo file in uso, illeggibili o cambiati rispetto al catalogo, il giro successivo
  arriva dopo 30 minuti invece di 2.

Le versioni 2.0 e 2.1 si aggiornano da sole: *Impostazioni › Aggiornamenti › Installa e
riavvia*.
