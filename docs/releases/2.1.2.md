Prism 2.1.2 keeps the NTFS disks up to date on PCs where their updates could stop: since 2.0, a file read through Windows could be taken for a damaged one, and the change journal of the whole disk waited behind it.

## Fixes

- **NTFS disks not updated** — Prism reads the files changed on an NTFS disk through Windows,
  which gives their records already corrected. A record can still hold, as ordinary data, the
  value Windows uses to check it: Prism took those records for damaged ones and tried the same
  update again every 16 seconds, so the catalog of the disk stayed where it was. On a company PC
  this kept C: and D: from being updated all night. Those records are now read normally.
- **An update that keeps failing** — whatever the reason, when the updates of an NTFS disk fail
  one after the other for 10 minutes, Prism reads the disk again from its file table, which
  takes seconds, and starts again from there.
- **Content analysis** — when the only files left are those changed since the catalog was
  updated, or images and videos changed since then, the analysis waits 30 minutes before the
  next round instead of 2.

## Install

Prism 2.0 and 2.1 update themselves: *Settings › Updates › Install and restart*. Otherwise
download `Prism_2.1.2_x64-setup.exe` below and run it (Windows 11, 64-bit). The installer is
not signed yet: if SmartScreen says "Windows protected your PC", choose *More info › Run anyway*.

## In italiano

Prism 2.1.2 tiene aggiornati i dischi NTFS sui PC dove gli aggiornamenti potevano fermarsi: dalla
2.0 un file letto tramite Windows poteva essere preso per rovinato, e il journal di tutto il
disco restava fermo dietro di lui. Ora quei file si leggono normalmente; in più, se gli aggiornamenti di un disco
NTFS falliscono di fila per 10 minuti, per qualsiasi motivo, Prism rilegge il disco (pochi
secondi) e riparte da lì. L'analisi del contenuto, quando restano solo file cambiati rispetto
al catalogo, aspetta 30 minuti prima del giro successivo invece di 2. Le versioni 2.0 e 2.1 si
aggiornano da sole: *Impostazioni › Aggiornamenti › Installa e riavvia*.
