Prism 2.1.1 behaves better on PCs with many disks and busy company file servers: fewer full re-reads of network folders, journal updates that no longer wait behind the content analysis, and OneDrive online-only files left alone.

## Fixes

- **Network folders of busy file servers** — when Windows lost change notifications on a large
  shared folder, Prism read the whole folder again every time: on a company server, a folder of
  3.2 million entries was read in full every 7 minutes for hours. A full re-read now waits at
  least 30 minutes after the previous one, and ten times what it took (at most 6 hours); the
  folders seen changing are still updated meanwhile.
- **Many disks at once** — the background analysis of four disks could take every worker of
  Prism, so the updates of the NTFS disks and new indexings waited until an analysis ended.
  Now the most recent analysis gives way within half a second.
- **OneDrive and other cloud files** — files kept only in the cloud (and offline files) are no
  longer read by the content analysis, which would download them or fail, and they no longer
  count as work left.
- **Files always in use** — when the only files left on a disk are in use or unreadable, the
  analysis tries them again every 30 minutes instead of every 2.
- **A disk left to be read again** — an NTFS disk whose update failed is read again by itself
  after 30 minutes, instead of at the next start; every failed job is now written in the log.
- **Updates** — a failed update check is tried again after an hour instead of the next day.

## Install

Prism 2.0 and 2.1 update themselves: *Settings › Updates › Install and restart*. Otherwise
download `Prism_2.1.1_x64-setup.exe` below and run it (Windows 11, 64-bit). The installer is
not signed yet: if SmartScreen says "Windows protected your PC", choose *More info › Run anyway*.

## In italiano

Prism 2.1.1 si comporta meglio sui PC con molti dischi e con i file server aziendali: le
cartelle di rete grandi non si rileggono più per intero ogni pochi minuti (al massimo ogni 30
minuti, e mai prima di 10 volte quanto è durata la lettura precedente), gli aggiornamenti dei
dischi non aspettano più dietro l'analisi del contenuto, i file di OneDrive solo nel cloud non
vengono letti (né scaricati), i file sempre in uso si riprovano ogni 30 minuti, un disco da
rileggere si rilegge da solo e un controllo degli aggiornamenti fallito si ripete dopo un'ora.
Le versioni 2.0 e 2.1 si aggiornano da sole: *Impostazioni › Aggiornamenti › Installa e
riavvia*.
