Prism 2.2.0 analyses large network folders much faster: each file is opened and read once, network shares read several files at a time, and pictures get their print from the same reading as their hash. It includes the fixes of 2.1.5, which was not published.

## Faster content analysis

On a company file server, the analysis of a shared folder with 2.5 million files took a day: 21
hours and a half for the hashes, one file at a time, and 5 more hours to read the pictures again
for their prints. Most of that time went in waiting for the server for each file, not in
reading it.

- **Each file is opened once.** Its size and date are read from the open file instead of
  opening it again by name.
- **Small files and pictures are read once.** Files up to 1 MB are read whole at the first
  step, which keeps their full hash too, and pictures get their print from the same bytes as
  their hash: no second and third reading.
- **Network shares read 4 files at a time.** Local disks still read one at a time: a hard disk
  is slower with two files at once, and on an SSD it makes no measurable difference.
- **Less memory while the analysis runs.** Counting the pictures and videos left no longer
  loads every file of the disk in memory.

## Fixes (from 2.1.5)

- **System disk left behind for 30 minutes**: Prism reads the files changed on an NTFS disk
  one after the other while programs keep working. When a program renamed a file over another
  between two of those reads, both seemed to have the same name: the update failed, and the
  catalog of the disk waited 30 minutes for a full reading. Prism now notices it and reads
  those files again 15 seconds later.
- **The same entries rewritten at every full reading**: when a file has several names in one
  folder (hard links, as the `git-*.exe` programs of Git for Windows), its names swapped their
  catalog entries at every full reading of the disk. The catalog was right, but written for
  nothing. Each name now keeps its entry.

## Diagnostics

- The log says how long each step of the analysis took, how much it read and how many files it
  read at a time, and every 10 minutes how far a long analysis got.
- The log says why Prism read a whole NTFS disk again instead of using its journal.
- The diagnostic package lists, for each disk, its entries and how far the content analysis
  got (files, images, videos), and for each running job its disk, progress and duration.

## Install

Prism 2.0 and 2.1 update themselves: *Settings › Updates › Install and restart*. Otherwise
download `Prism_2.2.0_x64-setup.exe` below and run it (Windows 11, 64-bit). The installer is
not signed yet: if SmartScreen says "Windows protected your PC", choose *More info › Run anyway*.

## In italiano

Prism 2.2.0 analizza molto più in fretta le cartelle di rete grandi: ogni file si apre e si
legge una volta sola, le cartelle di rete leggono più file alla volta e le immagini ricevono
l'impronta dalla stessa lettura dell'hash. Comprende le correzioni della 2.1.5, che non è stata
pubblicata.

- **Analisi più veloce**: su un file server aziendale l'analisi di una cartella condivisa con
  2,5 milioni di file richiedeva un giorno, quasi tutto passato ad aspettare il server per ogni
  file. Ora ogni file si apre una volta; i file fino a 1 MB e le immagini si leggono una volta
  sola (hash e impronta dagli stessi byte); le cartelle di rete leggono 4 file alla volta, i
  dischi locali uno. Contare le immagini e i video da fare non carica più in memoria tutti i
  file del disco.
- **Disco di sistema indietro di 30 minuti**: se un programma rinominava un file sopra un altro
  mentre Prism leggeva i file cambiati, l'aggiornamento falliva e il catalogo del disco
  aspettava 30 minuti una lettura completa. Ora Prism rilegge quei file 15 secondi dopo.
- **Le stesse voci riscritte a ogni lettura completa**: i nomi di un file con più hard link
  nella stessa cartella si scambiavano le voci del catalogo a ogni lettura. Ora ogni nome
  tiene la sua voce.
- **Diagnostica**: il log dice quanto è durato ogni passo dell'analisi, quanto ha letto e con
  quanti file alla volta, e ogni 10 minuti a che punto è un'analisi lunga; dice anche perché
  Prism ha riletto per intero un disco NTFS. Il pacchetto diagnostico riporta per ogni disco le
  voci e l'avanzamento dell'analisi, e per ogni lavoro in corso il disco, l'avanzamento e la
  durata.

Le versioni 2.0 e 2.1 si aggiornano da sole: *Impostazioni › Aggiornamenti › Installa e
riavvia*.
